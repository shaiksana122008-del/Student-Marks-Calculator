# Student Marks Calculator

A beginner-friendly web project that calculates a student's total marks, average, percentage, grade, and pass/fail status.

## Features

- Enter a student name
- Enter marks for five subjects
- Validate marks from 0 to 100
- Calculate total out of 500
- Calculate average and percentage
- Display a grade
- Check pass/fail status (minimum 35 marks in each subject)
- Responsive layout for mobile and desktop

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Enter the student's name and marks.
4. Click **Calculate Results**.

No installation or additional software is required.

## Grade Scale

| Percentage | Grade |
|---|---|
| 90–100% | A+ |
| 80–89.99% | A |
| 70–79.99% | B |
| 60–69.99% | C |
| 50–59.99% | D |
| Below 50% | F |

## Project Files

- `index.html` — page structure and form
- `style.css` — page styling and responsive layout
- `script.js` — calculations, validation, and grade logic
